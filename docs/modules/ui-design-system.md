# 界面与视觉设计

## 职责

- 确立青梧桌面客户端的视觉设计语言、色彩 Token、排版层级与交互规范。
- 坚持产品与交互克制，界面表现优先对齐 ChatGPT、Codex 等成熟桌面标杆，兼顾 Windows 办公场景的原生融合。
- 规范组件层级、色彩语义与操作动线，避免硬编码色彩碎片化与反直觉的交互布局。

## 主要代码入口

- 样式真值与 Token 定义：`src/renderer/src/native/native.css`（主题色、CSS 变量、暗色模式适配及全量组件样式）、`src/renderer/src/index.css`。
- 交互组件实现：
  - 问答与审批交互：`src/renderer/src/native/PendingInteraction.tsx`。
  - 对话流与消息卡片：`src/renderer/src/native/ChatList.tsx`、`ToolCard.tsx`。
  - 输入与运行控制：`src/renderer/src/native/MessageInput.tsx`、`RunningStrip.tsx`、`QueueStrip.tsx`。
  - 侧栏与工作区：`src/renderer/src/native/SessionSidebar.tsx`。
  - 顶栏与自绘菜单：`src/renderer/src/native/TitleBar.tsx`、`MenuPopupView.tsx`。

## 交互设计原则

1. **行业标准操作动线（Z 型视线流）**：
   - 用户视线自上而下阅读内容、自左向右浏览操作，最终视觉落脚点在右下角。
   - 弹窗、卡片与表单的操作区遵循**「辅助信息在左、操作动作居右、核心主推进动作最右」**的行业标准规范。
   - 严禁将主操作按钮（如「提交」「确定」）孤立置于左侧，严禁将破坏性或次要出口推至右下黄金操作位。
2. **退出出口与心智安全**：
   - 交互卡片（如提问卡片）提供明确的次要退路，文案必须使用用户视角的自然语言（如「直接打字沟通」「讨论一下」），不得使用「放弃整组问题」等暴露底层数据结构的生硬程序员用语。
   - 次要出口采用灰色弱化处理，不与主推进按钮争抢视觉重心。
3. **沉静与克制**：
   - 不滥用高饱和色彩与夸张动效；状态圆点、旋转环等均采用柔和灰与微动效（如 270° 柔灰慢速旋转环），保持办公界面的专注与沉静。

## 色彩体系（Design Tokens）

所有界面元素统一使用 CSS 变量，禁止内联书写任意十六进制游离色彩：

| Token 名称 | 亮色模式取值 | 暗色模式取值 | 语义与应用场景 |
| :--- | :--- | :--- | :--- |
| `--native-send` | `#3A83F7` | `#3A83F7` | **青梧品牌蓝**：主推进操作（发送、提交、允许一次、选项选中标记框与外框高亮） |
| `--native-send-fg` | `#ffffff` | `#ffffff` | 品牌蓝背景上的前景色（纯白文本与勾选图标） |
| `--native-bg` | `#ffffff` | `#212121` | 主对话区背景 |
| `--native-sidebar-bg`| `#f9f9fb` | `#181818` | 侧栏背景（与自绘顶栏左侧无缝融合，对齐 ChatGPT 桌面版） |
| `--native-hover` | `#f4f4f6` | `#2f2f2f` | 条目悬浮态背景、选项选中背景底色 |
| `--native-card-border`| `#e5e5e8` | `#383838` | 卡片外框、输入框常态细边框、浅色分割线 |
| `--native-fg` | `#1d1d1f` | `#ececec` | 主文本颜色 |
| `--native-muted` | `#8e8e93` | `#8e8e93` | 次要说明文本、题脚跳过、弱化出口按钮 |
| `--native-error` | `#e03131` | `#ff6b6b` | 校验失败提示、错误状态标记点 |

## 核心组件视觉与交互规范

### 1. 提问与审批卡片（`PendingInteraction.tsx`）
- **操作栏布局**：
  - 左侧：`.native-question-status`（`flex: 1` 占据剩余弹性宽度），承载错误提示文本或多题进度说明（如「已填 1 / 3 题」）。
  - 右侧：按钮群由左至右依次为：弱化次要出口（「直接打字沟通」） → 「上一题」（多题且大于第 1 题时可用） → **核心主按钮「下一题 / 提交」（Primary，青梧品牌蓝）**。
- **选项列表（Options）**：
  - 选中态：外边框高亮变更为 `--native-send`（品牌蓝），圆圈/方框 mark 背景填入品牌蓝，内部勾选对勾为纯白。
  - 单选交互支持点击即快速步进至下一题；多选与自由输入留在本题，提供明确「跳过本题」出口。
- **授权审批卡片（Approval）**：
  - 操作按钮居右下角：左侧为普通边框按钮「拒绝」，最右侧为品牌蓝主按钮「允许一次」。

### 2. 输入框与控制区（`MessageInput.tsx`）
- **平稳感知**：输入框使用浅灰细描边与轻微阴影，光标聚焦时保持边框与投影恒定，避免深黑突兀跳跃。
- **发送 / 停止按钮**：
  - 常显设计：空输入时显示灰色圆钮（灰底 + 浅灰箭头，禁用不可点）；有文字输入后点亮为品牌蓝；运行中变为同款品牌蓝底的实心方块停止按钮。

### 3. 滚动条（Scrollbar）
- 参照 InkMark 现代微质感风格，彻底去除 Windows 原生粗重灰色底轨。
- 采用透明底轨 + 8px 半透明圆角胶囊滑块（常态透明度 0.24，悬浮加深至 0.38），对话主视区保持 `scrollbar-gutter: stable` 避免抖动。
