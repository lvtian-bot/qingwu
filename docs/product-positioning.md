# 青梧 产品定位

本文记录青梧已经明确的产品出发点、定位、边界和长期方向。产品决策以本文为唯一依据。

## 场景由来

AI Agent 正在大量参与办公事务，但多数办公人员不会用命令行、不会安装 Node、不想在浏览器里敲地址。AI 的对话、审批、文件处理能力需要一个普通办公用户能直接双击打开的桌面入口。

青梧服务的就是这个过程：把 Agent 引擎封装成普通桌面软件，办公人员像打开 Word 一样打开它，把日常文书工作交给它。

## 产品定位

青梧是一个面向普通办公用户的办公 Agent 桌面客户端。当前直接基于 DeepSeek Harness：应用随包内置引擎，双击启动即用，用户不需要安装 Node、npm、dsh，也不需要打开浏览器。

不追求界面差异化，先验证「引擎封装 + 桌面分发」这条路是否成立；界面与办公能力按轮次逐步补全。

## 核心能力

1. 双击打开即用：自动启动内置 Harness，无需任何手动安装与命令行操作。
2. 桌面窗口内直接使用 Agent：会话、工具调用、文件读写等能力由 Harness 提供。
3. 干净启停：关闭应用后引擎进程随之退出，不留后台残留。
4. Windows 安装包：普通用户一键安装、启动、卸载。

## 产品边界

- 不做自研界面，直接使用官方 dsh web UI；界面替换按轮次推进，不一次性重写。
- 不做 Agent Loop、工具、沙箱、模型层：全部由 Harness 引擎提供，不自行实现。
- 不做办公文档能力（Word / Excel / PPT / PDF 处理）：该能力依赖 Harness 的 tool / skill 体系，属后续轮次。
- 不做多引擎切换（Pi 等）：后续按需评估，当前架构保留抽象边界以便切换。
- 首轮只出 Windows 发行版；macOS / Linux 暂不承诺。

## 发展方向

1. 可靠的引擎桌面壳：双击打开、自动启停、干净打包。
2. 桌面产品体验：托盘、快捷键、工作区 / 项目选择、设置页、自动更新、应用内状态。
3. 办公 Agent 能力：基于 Harness 的 tool / skill 体系沉淀办公场景能力（文档、表格、邮件、文件整理），并逐步把官方 UI 按模块替换为自研界面。
