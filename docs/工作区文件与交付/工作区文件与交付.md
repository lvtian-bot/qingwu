# 工作区文件与交付

## 职责

- 青梧的右侧面板是本模块的界面，对齐官方桌面版右栏骨架：面板没有标题行、tab 条就是整条上边，页签右端带「新建标签页」按钮（点击追加一枚开始页页签，类浏览器多页签），右上角搭全屏与收起两个面板控件；展开默认落「开始页」（入口卡片）；普通形态贴靠右栏、会话区让位（默认宽 600px，可拖 240–720px，不超过窗口一半），全屏形态覆盖窗口（窗口低于 768px 自动全屏）。面板宽度全局统一记忆，打开的页、选中页、展开状态与呈现方式按会话独立存 localStorage，切会话各自恢复；没有选中会话就没有面板入口。
- 交付物不设独立面板页：present 工具的 `deliverables/presented` 事件按轮折叠进会话流，在每轮收尾渲染交付卡片（单个一行、多个双列网格、超过四个折叠；文件类型图形 + 说明 + 打开/定位）。卡片主体点击在右侧面板打开该文件预览；打开/定位走系统桌面操作。
- 面板提供工作区文件树（从会话工作区根逐层浏览，点击文件在面板内预览）与文件预览页（文本/代码按行分页、Markdown 渲染、图片展示、Office 与 PDF 文档高清多页预览，未知类型纯文本兜底）。文件与已展开目录自动跟随变化刷新。在 Markdown 预览页中点击本地文件链接（含相对当前文档路径、相对工作区根路径、绝对路径及行号锚点）时，优先以当前文档所在目录为基准解析并自动在面板内新建标签页（或聚焦已打开的同一文件页签）；外部网络链接（http/https）放行至系统浏览器。
- 主进程执行系统桌面操作（系统默认程序打开、资源管理器定位、终端、本地图片读取、Office/PDF 文档转码与多页渲染），渲染层经 preload 暴露的 IPC 调用。

## 主要代码入口

- 面板骨架与布局存储：`src/renderer/src/native/RightPanel.tsx`、`panel/layout.ts`。
- 开始页、文件树与预览页：`panel/PanelGuide.tsx`、`panel/PanelFiles.tsx`、`panel/PanelPreview.tsx`；自绘图形（文件类型徽标、引导插画、控件）：`panel/glyphs.tsx`。
- 主进程文档预览与转码服务：`src/main/document-preview.ts`（复用随包内置的 LibreOffice Kit 原生/PDFium 渲染器与轻量结果缓存）。
- 数据层（workspaceFiles RPC 与 changes 监听流封装、路径与文件类型工具）：`panel/workspace-files.ts`；线上契约类型：`protocol.ts` 的 workspaceFiles 段。
- 会话流交付卡片与折叠：`DeliverableCards.tsx`；`events.ts`（foldChatItems 的 deliverables 按轮折叠、foldTodos 任务清单折叠）。

## 技术约束

- 面板数据全部来自引擎已挂载的 dsh 插件（qingwu profile 与官方桌面版 bundle 组合一致，无需新增插件）：`@deepseek-ai/dsh-api-workspace-files` 提供分页文本读取（`workspaceFiles/read`）、目录列举（`list`）、文件身份（`stat`）与按路径监听（`changes` 流）；交付事件由 present 工具写入会话日志，随 `session/follow` 流到达。各方法首个线上参数固定为 `workspaceFileScopeId`（值即会话 id，Host 据此解析文件系统权限）；契约由 `tests/contract-installed-dsh.test.cjs` 对已安装引擎的 `/remote` 出口校验，升级 dsh 时必须重跑。
- 目录列举与目录监听限定在工作区内；文件读取与文件监听按引擎文件系统的读取权限。文本按行分页（界面每页 2000 行，引擎单页上限 5000，`eof` 判断终止）；图片预览复用主进程本地图片通道（20MB 上限）；Office（Word/Excel/PowerPoint）与 PDF 复用随包内置的 LibreOffice Kit 通道进行高清多页预览。其中 Office 办公文档统一先经 LibreOfficeKit 导出为保真矢量 PDF，再交由 PDFium 栅格化为多页 PNG，彻底消除 Windows 高分屏 DPI 缩放下直接切片产生的左上角裁切与放大缺陷，保证 100% 完整展现幻灯片和页面；并由主进程建立内存与文件缓存，保留系统默认程序打开兜底。
- 监听流生命周期归页面所有：文件树的根与每个已展开目录、预览页的当前文件各持有一条 `workspaceFiles/changes` 逻辑流，页面折叠、关闭或卸载时取消。桥把 `error`/`end` 终态帧转译为 `stream/error`、`stream/end` 值后保留流注册，消费方收到终态必须主动 cancel（见 `panel/workspace-files.ts` 的 watchWorkspacePath）。
- 面板宽度对齐官方 DSH 与成熟桌面标杆，作为全局视口容器属性在 localStorage 统一记忆（`qingwu.panel.width`，默认 600px，拖拽或双击重置时更新，旧版本 500px 默认值平滑抬升至 600px），切换会话不改变全局已调整宽度；展开状态、全屏模式与页签内容（打开的页、选中页）按会话独立存储在 localStorage（`qingwu.panel.layout.<sessionId>`）；展开且为空才播种开始页；开始页是「新建标签页」的落点页，页签样式与关闭控件不分开始页和其他页，选中页签显示活动框；从开始页点击入口或经导航（交付卡片、Ctrl+P）打开文件页时替换当前开始页页签，打开文件预览与「新建标签页」则追加页签；关闭最后一个页签时整列收起、布局回到空，下次展开再播种。载入时校验字段类型与页成员关系，无效记录只丢弃对应会话的 key。
- 官方 `dsh-client-ui-primitives` 原子组件包未声明运行时依赖（katex、simple-icons 等不在本项目 dependencies，打包后会缺模块），不引入；面板内文件类型图形、引导插画与控件图标全部自绘 SVG，配色对齐官方大类色板。
