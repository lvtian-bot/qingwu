## 暂不考虑

- [ ] macOS / Linux 发行版
- [ ] 安装提速：根因是安装释放一万余个依赖小文件、杀软逐文件实时扫描。遥测链（OpenTelemetry 全家与四个遥测插件包，约 1500 文件）已裁剪：`--patch` 注入禁用补丁 + 打包排除，随引擎遥测一并停用（见 docs/dsh运行与连接/dsh运行与连接.md）。首启动延迟解压维持不做：总时长不变，只是把等待挪到首启动。
- [ ] 任务终止后排队消息自动发车/快捷唤醒：保持对齐 DSH 官方当前行为（用户手动终止任务时停稳当前步骤并保留收件箱队列，不自动唤醒后续排队消息）；暂不自研特殊的自动发车或回流机制，避免与官方底层调度脱节，后续持续追踪 DSH 官方针对该场景的交互与调度演进并在上游调整后跟进
- [ ] 插件市场与第三方插件安装：dsh 插件市场为实验性组合包且无官方公共索引源，第三方 Bundle 安装暂无发现渠道；上游市场生态成熟、提供正式索引源后跟进
- [ ] 插件管理（已装插件）：dsh 插件均为引擎内部组件（cordis bundle），无第三方生态，面向办公用户无实际管理场景；且与产品语境的「插件/技能包」概念错位，联网搜索等用户可感知能力已由对应设置分区覆盖。dsh 出现用户可感知的插件生态后再评估
- [ ] 子智能体设置：dsh 无用户可编辑的子代理定义，可配置项仅嵌套深度、并行容量、模型白名单等技术参数，办公用户无调整需求；上游能力形态变化后再评估
- [ ] MCP 管理：`dsh-mcp-client` 默认未随包启用且无管理接口，接入需写引擎补丁、与「主进程不重写用户引擎补丁」约定冲突；上游将 MCP 纳入正式配置面后跟进
- [ ] OpenAI Codex 模型接入：引擎目录内置该供应商，但 ChatGPT 账号授权登录在当前引擎版本（0.2.2-rc.3）无对外接口，官方桌面版同样未提供入口、实测不可用，本机 Codex CLI 登录文件引擎不读取；凭据库全局共享，上游开放授权接口后，设置页提供「登录 ChatGPT」入口即可接入（调查结论见 [Codex模型接入问题记录](设置与模型/Codex模型接入问题记录.md)）
- [ ] 远程连接：引擎已有 `remoteAccess/follow` 端点（面向非 owner Peer 的访问快照），青梧未消费；跟踪上游远程访问方案演进，官方形成可用方案后评估跟进
