# 青梧 第一轮产品开发需求（V0.1.0）

本轮只做一件事：把 DeepSeek Harness 封装成一个普通办公用户能双击打开、不用任何命令行的 Windows 桌面应用。不写自研界面，不改引擎。

## 目标

用户双击安装好的「青梧」，窗口打开，看到可用的 Harness 界面，能正常完成 Agent 对话与工具操作；关闭应用后不残留后台进程。全程用户不需要安装 Node、npm、dsh，也不需要打开浏览器。

## 范围

### 本轮要做

1. Electron 主进程：
   - 启动时自动拉起内置的 @deepseek-ai/dsh（dsh web），等待服务就绪。
   - 就绪后创建桌面窗口，加载官方 Web UI（127.0.0.1:3080）。
   - 退出时停掉 Harness 子进程；异常退出给用户明确提示。
2. 依赖内置：@deepseek-ai/dsh 作为 dependency 随应用打包，锁定版本（当前 0.1.0-rc.7）。
3. 基础壳：窗口标题「青梧」、应用图标、合理默认尺寸、隐藏菜单栏。
4. Windows 安装包：一键安装、启动、卸载；安装目录干净。
5. 工程基础：git 仓库、npm 依赖管理、基础脚本（启动 / 构建）、README 与治理文档就位。

### 本轮不做（明确排除）

- 自研界面：UI 直接用官方 dsh web。
- Agent Loop、工具、沙箱、模型：全部由 Harness 提供，不碰。
- 办公文档能力（Word / Excel / PPT / PDF）。
- 托盘、快捷键、工作区 / 项目选择、设置页、自动更新：放第二轮。
- macOS / Linux 发行版。
- 多引擎切换（Pi 等）。

## 验收标准

1. 安装后在干净 Windows 环境双击启动，无需任何手动安装或命令行，直接进入 Harness 界面。
2. 应用内可正常发起会话、完成工具调用（能力随引擎版本）。
3. 关闭窗口后 Harness 进程退出，任务管理器无残留。
4. 卸载后无残留文件与进程。
5. 升级 dsh 版本需重新验证后再发布，不自动跟随最新。

## 依赖与版本

- Node.js：>= 22.19（开发环境；当前机器 v24.18.0）
- @deepseek-ai/dsh：0.1.0-rc.7（锁定）
- electron：43.4.1
- npm 源：npmmirror（本机已配置）
